## EJ-07-02-02 — Marko repite trabajo con un bucle `for`

> [!abstract] Ficha de la práctica
> ### 📌 `B0.S.7.2.2` — Marko repite trabajo con un bucle `for`
> - **Fase 7** (Leer y escribir un script de bash) · **Nivel 2** (Básico)
> - **🎬 Playlist:** `B0_Curso_Shell`
> - **📹 Nombre del vídeo:** `B0.S.7.2.2 · Marko repite trabajo con un bucle for`

> [!info] Situación
> Marko tiene que crear las seis carpetas de departamento, con su grupo y sus permisos. Son dieciocho comandos escritos a mano. Escribe los quince primeros bien y en el dieciséis pone `contabilida`. Y luego pasa una hora buscando por qué falla una sola carpeta.

- **🎯 Objetivo real:** ejecutar la misma secuencia de comandos sobre una lista de elementos.
- **🧩 Problema que resuelve:** repetir a mano no es solo lento: **es donde se meten las erratas**. Un bucle escribe el comando una vez y lo aplica seis veces exactamente igual.

## 📚 Fundamento

> [!info] 📍 Punto de partida — de dónde vienes
> Este ejercicio trabaja sobre **`/srv/lab/departamentos`**, el árbol que montaste en la **Fase 5** ([EJ-05-02-02](../fase-5-discos-y-montajes/EJ-05-02-02.md)). Compruébalo antes de empezar:
> ```
> ls -l /srv/lab/departamentos
> ```
>
> **Si no está** —otra sesión, otra instantánea, o te lo saltaste— reconstrúyelo:
> ```
> for d in facturacion contabilidad comercial logistica rrhh becarios; do
>   sudo groupadd -f "$d"
>   sudo mkdir -p "/srv/lab/departamentos/$d"
>   sudo chgrp "$d" "/srv/lab/departamentos/$d"
>   sudo chmod 2770 "/srv/lab/departamentos/$d"
> done
> ls -l /srv/lab/departamentos
> ```

> [!info] Antes de empezar: la estructura del `for`
> ```
> for d in facturacion contabilidad comercial; do
>     echo ">>> Creando carpeta de $d"
>     sudo mkdir -p "/srv/samba/departamentos/$d"
>     sudo chown "root:$d" "/srv/samba/departamentos/$d"
>     sudo chmod 2770 "/srv/samba/departamentos/$d"
> done
> ```
>
> Se lee tal cual: **para cada `d` de esta lista, haz esto**.
>
> | Trozo | Qué es |
> | :--- | :--- |
> | `for d in ...` | `d` es la variable que va tomando cada valor |
> | `facturacion contabilidad ...` | la lista, separada por **espacios** |
> | `do` … `done` | el bloque que se repite |
> | `$d` dentro | el valor de esta vuelta |
>
> La lista puede venir de varios sitios:
>
> ```
> for d in facturacion contabilidad; do ...          # escrita a mano
> for d in $DEPARTAMENTOS; do ...                    # de una variable
> for f in /srv/samba/departamentos/*; do ...        # de un comodín
> for u in $(getent group facturacion | cut -d: -f4); do ...   # de un comando
> ```
>
> Y el `;` antes de `do` es porque `for ...` y `do` son dos instrucciones. Si pones `do` en su propia línea, no hace falta el `;`. Las dos formas son correctas.

> [!tip] Idea clave
> Es **la cadena de montaje otra vez**, pero con las piezas puestas en fila. En vez de coger cada pieza y llevarla a mano a las tres máquinas, montas el proceso una vez y las piezas van pasando solas. Y todas reciben exactamente el mismo tratamiento — que es justo lo que quieres en permisos.

> [!warning] El error nº1: ejecutar un bucle destructivo sin haberlo probado con `echo`
> Un `for` con un error de ruta no se equivoca una vez: **se equivoca seis**. Y muy rápido.
>
> ```
> for d in facturacion contabilidad; do
>     sudo rm -rf "/srv/samba/$d"      # ← ¿seguro que es esta ruta?
> done
> ```
>
> **La costumbre que te salva:** ejecuta primero el bucle con `echo` delante de los comandos peligrosos.
>
> ```
> for d in facturacion contabilidad; do
>     echo sudo rm -rf "/srv/samba/$d"
> done
> ```
>
> Te imprime **exactamente** los comandos que se ejecutarían, sin ejecutarlos. Los lees. Y si están bien, quitas el `echo`.
>
> Es el `sed` sin `-i` del `EJ-03-04-02`, aplicado a los bucles.

> [!example] Vocabulario de esta práctica
> - **`for`:** repite un bloque para cada elemento de una lista.
> - **`do` / `done`:** abren y cierran el bloque que se repite.
> - **Variable de bucle:** la que toma cada valor: `d` en `for d in ...`.
> - **Ensayo con `echo`:** poner `echo` delante para ver qué se ejecutaría.
> - **Iteración:** cada vuelta del bucle.

> [!info] 🔗 Dónde lo vas a usar
> **Fase 6 de Boochan**: `for d in comercial logistica rrhh becarios; do ... mkdir ... chown ... chmod 2770 ... done` para crear cuatro departamentos. **Fase 5**: bucles para crear grupos y comprobar usuarios. **Fase 7**: `for d in facturacion contabilidad ...; do getfacl -p ... done` para auditar. Y todos los verificadores: `for d in $DEPARTAMENTOS; do getent group "$d" ...`.

> [!example] Paso 1 — Tu primer bucle, en la terminal
> ```
> for d in facturacion contabilidad comercial; do
>     echo "Departamento: $d"
> done
> ```
>
> Tres vueltas, una por elemento. La variable `d` va cambiando.
>
> Puedes escribirlo también en una línea:
>
> ```
> for d in facturacion contabilidad comercial; do echo "Dpto: $d"; done
> ```
>
> Las dos formas son iguales. En un script, mejor en varias líneas: se lee.

> [!example] Paso 2 — Ensaya antes de ejecutar
> ```
> for d in facturacion contabilidad comercial logistica rrhh becarios; do
>     echo sudo mkdir -p "/srv/lab/departamentos/$d"
>     echo sudo chown "root:$d" "/srv/lab/departamentos/$d"
>     echo sudo chmod 2770 "/srv/lab/departamentos/$d"
> done
> ```
>
> **Lee los dieciocho comandos que ha impreso.** ¿Son los que querías? ¿Las rutas están bien?
>
> Este paso cuesta diez segundos y evita desastres.

> [!example] Paso 3 — Ahora sin `echo`
> ```
> for d in facturacion contabilidad comercial logistica rrhh becarios; do
>     sudo groupadd -f "$d"
> done
>
> for d in facturacion contabilidad comercial logistica rrhh becarios; do
>     echo ">>> Creando carpeta de $d"
>     sudo mkdir -p "/srv/lab/departamentos/$d"
>     sudo chown "root:$d" "/srv/lab/departamentos/$d"
>     sudo chmod 2770 "/srv/lab/departamentos/$d"
> done
>
> stat -c '%n  %U:%G  %a' /srv/lab/departamentos/*
> ```
>
> Dieciocho comandos, seis carpetas, **cero erratas**. Y todas exactamente iguales, que es lo que importa en permisos.

> [!example] Paso 4 — Saca la lista a una variable
> ```
> DEPARTAMENTOS="facturacion contabilidad comercial logistica rrhh becarios"
>
> for d in $DEPARTAMENTOS; do
>     printf '%-16s ' "$d"
>     getent group "$d" || echo "NO SE VE"
> done
> ```
>
> La lista se escribe **una vez**, arriba, y se usa en todos los bucles del script. Si mañana hay un departamento más, se toca una línea.
>
> **Fíjate:** aquí `$DEPARTAMENTOS` va **sin comillas** a propósito, porque queremos que la shell la parta por los espacios. Es la única excepción a la regla de entrecomillar, y conviene saber que es deliberada.
>
> Así es exactamente como está escrito el `verificar_fase7.sh` de Boochan.

> [!example] Paso 5 — Recorre ficheros con un comodín
> ```
> for f in /srv/lab/departamentos/*; do
>     echo "=== $f"
>     ls -ld "$f"
> done
> ```
>
> Aquí la lista la genera la shell expandiendo el `*` — lo que viste en el `EJ-03-04-01`.
>
> Y así se audita una estructura entera:
>
> ```
> for d in /srv/lab/departamentos/*; do
>     echo "=== $d"
>     getfacl -p "$d" 2>/dev/null | grep -E "^group:[^:]"
> done
> ```

> [!example] Paso 6 — Métele el bucle a un script
> ```
> cd ~
> nano crear-deptos.sh
> ```
>
> ```
> #!/bin/bash
> # crear-deptos.sh - crea la estructura de departamentos
> # Marko - Boochan Networks S.L.
>
> BASE="/srv/lab/departamentos"
> DEPARTAMENTOS="facturacion contabilidad comercial logistica rrhh becarios"
>
> for d in $DEPARTAMENTOS; do
>     echo ">>> $d"
>     sudo mkdir -p "$BASE/$d"
>     sudo chown "root:$d" "$BASE/$d"
>     sudo chmod 2770 "$BASE/$d"
> done
>
> echo ""
> echo "--- Resultado ---"
> stat -c '%n  %U:%G  %a' "$BASE"/*
> ```
>
> ```
> chmod +x crear-deptos.sh
> ./crear-deptos.sh
> ```
>
> **Ese script es, prácticamente, el paso 4 de la Fase 6 de Boochan.**

> [!example] Paso 7 — Vuelve a ejecutarlo
> ```
> ./crear-deptos.sh
> ```
>
> Funciona igual. Un script que puedes ejecutar dos veces sin romper nada se llama **idempotente**, y es una propiedad muy valiosa: significa que puedes relanzarlo tras un fallo sin miedo.
>
> `mkdir -p` y `chmod` lo son por naturaleza. Otros comandos no. Piénsalo cuando escribas los tuyos.

## 🚩 Errores y verificación

> [!warning] Errores típicos (evítalos)
> | Error | Qué pasa | Cómo evitarlo |
> | :--- | :--- | :--- |
> | Ejecutar un bucle destructivo sin ensayo | Te equivocas seis veces en un segundo | `echo` delante primero. Lee. Luego quítalo. |
> | Olvidar `done` | La shell se queda esperando con el prompt `>` | Cierra el bloque. `Ctrl`+`C` para abortar. |
> | Entrecomillar la lista (`"$DEPARTAMENTOS"`) | El bucle da UNA vuelta con toda la lista junta | La lista va sin comillas; los usos de `$d`, con comillas. |
> | Usar la variable del bucle fuera de él | Conserva el último valor y confunde | Úsala dentro del `do`/`done`. |

> - `stat -c` muestra las seis correctas y todas iguales.
> - Has ensayado con `echo` antes de ejecutar.
> - El script se puede ejecutar dos veces sin romper nada.
