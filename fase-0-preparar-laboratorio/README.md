# Fase 0 · Prepara el laboratorio Shell

> [!important] Debes realizar ambas ediciones: Cole y Casa. Selecciona aquí el contexto de esta sesión; cada edición se completa en su propio laboratorio y proyecto.

> **Módulo:** SOR · Esta es la fuente docente. Las ejecuciones del alumno se hacen en espacios externos y separados: `SOR_Shell_Cole/Boveda_Shell_Cole` o `SOR_Shell_Casa/Boveda_Shell_Casa`.

## Elige un recorrido

- **[Fase 0 · COLE](Cole/README.md):** recorrido autónomo con bóveda, repositorio de apuntes, VM y playlist propios.
- **[Fase 0 · CASA](Casa/README.md):** recorrido autónomo desde cero, con bóveda, repositorio de apuntes, VM y playlist propios.

Cada guía de contexto lleva el orden de las cuatro prácticas, las comprobaciones previas, las instrucciones completas y su estructura de apuntes. No uses rutas antiguas dentro de `SOR` ni reutilices el otro contexto.

## Prácticas incluidas

1. F0.1 · Descargar y comprobar la ISO.
2. F0.2 · Comprobar compatibilidad y crear la VM.
3. F0.3 · Instalar Ubuntu Server.
4. F0.4 · Configurar SSH con una clave del laboratorio y cerrar la fase.

La fuente docente común y los archivos antiguos que aún quedan en esta carpeta no constituyen un recorrido ejecutable para el alumno. Entra por uno de los dos recorridos anteriores.
