# FASE 3 — Redirección, tuberías y texto

**Duración estimada:** 5 h · **Idea central:** Encadenar comandos y preguntar lo que quieres saber

Marko sabe ejecutar comandos. El problema es que le devuelven sesenta líneas y él busca una. Esta fase va de conectar comandos entre sí, filtrar, y guardar el resultado donde sirva.

**La idea central de la fase:** cada comando hace una cosa, y tú los combinas. Es la filosofía de Unix entera.
